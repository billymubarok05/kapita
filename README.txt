==================================================
VOLCANO EXPLORER 3D
MEDIA PEMBELAJARAN INTERAKTIF
==================================================


DESKRIPSI
---------

Volcano Explorer 3D adalah media pembelajaran interaktif
yang digunakan untuk mengenalkan struktur dan proses
gunung api melalui visualisasi interaktif.

Pengguna dapat mengeksplorasi bagian gunung api,
membaca materi, melihat simulasi erupsi, dan mengerjakan
kuis evaluasi.


==================================================

==================================================

HTML5
CSS3
JavaScript
Visual Studio Code

==================================================
FITUR MEDIA
==================================================

1. MENU UTAMA
--------------

Menampilkan pengenalan Volcano Explorer.


2. EKSPLORASI 3D
----------------

Pengguna dapat memilih bagian:

- Kawah
- Kerucut gunung api
- Lava
- Pipa magma
- Ruang magma
- Kerak bumi

Setiap bagian memberikan informasi pembelajaran.


3. ROTASI MODEL
---------------

Model gunung dapat diputar menggunakan:

↶
Putar kiri

⟳
Reset

↷
Putar kanan


4. ZOOM
--------

Gunakan:

+
Untuk memperbesar model.

-
Untuk memperkecil model.


5. MATERI
---------

Materi mencakup:

- Pengertian gunung api
- Magma
- Erupsi
- Kerak bumi


6. SIMULASI ERUPSI
------------------

Menampilkan animasi:

- Asap
- Lava
- Partikel
- Api


7. KUIS
-------

Terdapat 5 pertanyaan.

Setiap jawaban benar mendapatkan:

20 poin


Nilai maksimum:

100


==================================================
CARA MENJALANKAN
==================================================

1. Buka Visual Studio Code.

2. Pilih:

   File
   Open Folder

3. Pilih folder:

   volcano-explorer

4. Pastikan file berikut berada di folder yang sama:

   index.html
   style.css
   script.js
   README.txt


==================================================
MENJALANKAN PROJECT
==================================================

Cara pertama:

Klik dua kali:

index.html


Cara kedua yang disarankan:

Install extension:

Live Server


Kemudian:

Klik kanan index.html

Pilih:

Open with Live Server


Browser akan membuka project.


==================================================
TUJUAN PEMBELAJARAN
==================================================

Setelah menggunakan media ini, pengguna diharapkan
dapat:

1. Menjelaskan pengertian gunung api.

2. Mengenali bagian-bagian utama gunung api.

3. Menjelaskan pengertian magma dan lava.

4. Menjelaskan fungsi ruang magma.

5. Memahami konsep sederhana proses erupsi.

6. Menguji pemahaman melalui kuis.

==================================================
CATATAN
==================================================

Visualisasi gunung pada project ini dibuat menggunakan
HTML dan CSS sehingga tidak membutuhkan file model 3D
eksternal.

Project dapat dikembangkan lebih lanjut menggunakan
model 3D sebenarnya seperti format:

.glb
.gltf
.obj

atau library 3D seperti Three.js.
